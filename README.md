# 🗳️ Urna Eletrônica — Simulação em JavaScript

Projeto desenvolvido com HTML, CSS e JavaScript puro, com foco em lógica de programação, manipulação do DOM e controle de estado da aplicação.

A aplicação simula o funcionamento de uma urna eletrônica, permitindo iniciar a votação, digitar o número do candidato, votar em branco, corrigir e confirmar o voto, finalizando com a tela FIM.

## 🧠 Funcionamento da Aplicação

A votação inicia ao pressionar CONFIRMAR

O usuário digita o número do candidato

As informações do candidato aparecem dinamicamente

É possível votar em branco

O voto pode ser corrigido antes da confirmação

Após confirmar, o sistema exibe a tela FIM
